## v1.1.0 (2026-05-07) - 이모지 0-Delay 소환 및 3중 클립보드 붙여넣기 탑재

`mongTang.md` v1.1.0이 출시되었습니다. 이번 업데이트에서는 무지연 네이티브 이모지 연동 및 3중 미디어 복사/붙여넣기 파서 탑재 등 다양한 프론트엔드/백엔드 최적화가 이루어졌습니다.

### 🚀 주요 변경 사항

#### 1. 신규 기능 (Added)
- **초고속 무지연 네이티브 이모지 연계**: Rust FFI 기반으로 윈도우 순정 이모지 선택판(`Win + .`) 및 macOS 이모지 패널을 지연 시간 없이 마우스 클릭으로 다이렉트 호출 지원
- **전천후 클립보드 3중 미디어 수혈 엔진**: 이진 파일 복사본, HTML 이미지 스니펫, 순수 짤방 웹 주소(Tenor 등)를 가리지 않고 마우스 붙여넣기(`Ctrl+V`) 시 자동으로 마크다운 이미지 문법(`![gif](...)`)으로 변환 삽입하는 강력한 미디어 복제 보강 완료

#### 2. 변경 및 개선 사항 (Changed)
- **에디터 핵심 단축키 통합 조율**: 리액트 상태 리렌더링 과정에서 소실되던 실행 취소(`Ctrl+Z`), 다시 실행(`Ctrl+Y`), 모두 선택(`Ctrl+A`) 단축키를 자체 히스토리 버퍼로 직접 유도 정합하여 기능 무결성 확보
- **한글/다국어 레이아웃 대칭 보정**: 한국어 사전에 5번째 핵심 기능 설명줄을 수혈하여 양국 언어 토글 시 세로 높이가 1px의 오차 없이 완벽하게 칼정렬되도록 조율

#### 3. 버그 수정 (Fixed)
- **전역 우클릭 차단 및 미리보기 영역 무효화**: 에디터 영역 밖 및 읽기 전용인 미리보기 패널에서 불필요하게 튀어나오던 커스텀 메뉴들을 지능적으로 무효 필터링하고 전역 크로미움 기본 메뉴 강제 차단
- **메뉴 붙여넣기 뷰포트 이탈 진압**: 마우스 메뉴 클릭으로 붙여넣기를 수행할 시 화면이 상하좌우로 격렬하게 흔들리던 현상을 `preventScroll` 초점 기법과 스크롤 좌표 캡처 엔진으로 완벽히 소탕
- **타입스크립트 경고 6선 완벽 소거**: 툴바 내부에 남아있던 미사용 상태 훅 잔재들을 말끔히 삭제하여 무결점 0-Warning 빌드 시스템 성취
